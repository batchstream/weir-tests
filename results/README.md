# Recorded measurements

Only explicitly qualified paired runs belong here. Raw JSON preserves operation counts, timing, verification, backend policies, exact source and fixture settings. Local working reports remain under ignored `results/local/`.

The initial profile uses one logical operation per client call, a fixed working set, alternating direct/Weir ordering, matching acknowledgements and an independent postflight. Ratios describe the recorded hardware and configuration. CI smoke measurements establish execution validity without enforcing a performance threshold.
