# Security policy

## Report a vulnerability

Use GitHub's private
[Report a vulnerability](https://github.com/batchstream/weir-tests/security/advisories/new)
form. Include the affected repository version or commit, reproduction steps, impact,
and relevant deployment settings with credentials and private data removed.
Please keep exploit details out of public issues while a report is being
investigated.

## Versions

This repository holds test tooling and has no releases; check `main`. Report
vulnerabilities in the server or SDK to [weir](https://github.com/batchstream/weir/security/advisories/new)
or [weir-go](https://github.com/batchstream/weir-go/security/advisories/new).
